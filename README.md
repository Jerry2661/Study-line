# Studyline

Studyline is a Python desktop app that helps students organize homework, exams, and study time.

## Features
- Add, edit, delete, and complete homework
- Sort homework by due date and priority
- Add and delete exams
- Store homework and exams with SQLite
- Generate a daily homework and exam review plan
- Show reminders for deadlines today or tomorrow
- Dashboard for upcoming homework and exams

## Technology
- Python
- Tkinter
- SQLite

## Run
```bash
python app.py
```

No external packages are required.
